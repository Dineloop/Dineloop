HOSTING SETUP (free)
====================
Recommended: Cloudflare Pages. Alternatives are listed below.
The app is a static site: no build step, no server.

A) CLOUDFLARE PAGES (recommended)
  1. dash.cloudflare.com -> sign up (free).
  2. Left menu -> "Workers & Pages" -> "Create" -> choose "Pages" -> "Connect to Git".
  3. Authorize GitHub, select the repository "dineloop" (private is fine).
  4. Build settings:
       Framework preset: None
       Build command: leave EMPTY
       Build output directory: /     (if it complains, type a single dot  . )
  5. Click "Save and Deploy". After about a minute you get https://dineloop.pages.dev
  6. Custom domain (optional): your Pages project -> "Custom domains" -> "Set up a custom domain".
  7. Copy the live address into Supabase: Authentication -> URL Configuration -> Site URL.

B) NETLIFY
  app.netlify.com -> "Add new site" -> "Import an existing project" -> GitHub -> dineloop.
  Build command: empty. Publish directory: .   Deploy.
  Quick test without GitHub: app.netlify.com/drop and drag the dineloop-cloud folder.

C) VERCEL
  vercel.com -> "Add New" -> "Project" -> import the repo.
  Framework Preset: Other. No build command. Deploy.

D) GITHUB PAGES (only if the repo is Public)
  Repo -> Settings -> Pages -> Source: "Deploy from a branch" -> main / (root) -> Save.
  Free GitHub accounts need a public repo for Pages. Because your repo should be private, prefer A.

INSTALL AS AN APP
  Android/Chrome: open the site -> menu (3 dots) -> "Install app" or "Add to Home screen".
  Windows Chrome: address bar install icon -> Install.
  iPhone/iPad Safari: Share -> "Add to Home Screen".

TEST CHECKLIST AFTER GOING LIVE
  [ ] Site opens and shows the login screen.
  [ ] Login works and the top bar says CLOUD SYNC.
  [ ] A bill on device 1 shows on device 2.
  [ ] Print bill works (see file 05).
