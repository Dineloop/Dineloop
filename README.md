# DineLoop
Restaurant POS + loyalty + WhatsApp marketing. Static web app (index.html) + Supabase backend.

- index.html ........ the app
- sql/ .............. run these in Supabase SQL Editor, in number order
- supabase/functions/ Edge Functions (WhatsApp send, AI assistant)
- docs/ ............. step-by-step setup guides (.txt), start with 00_START_HERE.txt

Never commit secret keys. Secrets live only in Supabase (supabase secrets set ...).
